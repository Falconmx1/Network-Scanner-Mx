# 📊 Network Scanner Mx

> Escáner de dispositivos en red local estilo pro, hecho en Python 🐍

## 🚀 Características
- Detecta automáticamente tu red actual
- Muestra IP, MAC y fabricante por OUI
- Rápido y sin dependencias pesadas
- Soporta Windows, Linux y macOS

## 📦 Instalación
```bash
git clone https://github.com/Falconmx1/Network-Scanner-Mx.git
cd Network-Scanner-Mx
pip install -r requirements.txt

🔧 Uso
# Escaneo automático
python scanner.py

# Especificando rango manual
python scanner.py -r 192.168.1.0/24
